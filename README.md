# 🦋 鸢青结单表处理系统

一个专为游戏代练团队设计的结单表处理工具，支持自动解析、数据管理和统计分析。

## 功能特性

- 📝 **智能解析** - 粘贴结单表文本，自动提取各项数据
- 📅 **日期范围** - 灵活选择统计日期范围
- 📊 **实时统计** - 自动计算总营业额和流水排名
- 📋 **数据管理** - 记录表格展示，支持删除操作
- 📥 **导出功能** - 一键导出 CSV 文件
- 💾 **本地存储** - 数据持久化保存

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

### 生产构建

```bash
npm run build
```

## 使用说明

1. **输入结单表** - 在文本框中粘贴结单表文本
2. **选择日期** - 设置订单日期
3. **解析数据** - 点击「解析结单表」按钮
4. **确认添加** - 检查解析结果，点击「添加记录」
5. **统计查看** - 在统计区域查看营业额和排名
6. **导出数据** - 点击「导出 CSV」下载表格
